# Azba — AI Portfolio

A playful, animal-themed portfolio built with React + Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Open Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Vercel should detect **Vite** automatically.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

## Main content

Edit `src/main.jsx`:
- `projects` controls project cards and case studies.
- `experience` controls the timeline.
- Hero/About/Skills text is in the `App` component.

Edit `src/styles.css` for the visual system, colors, motion and layout.
